# Welcome to Improve Engine

Welcome to our new website! We're excited to launch this modern, responsive, and accessible platform built with MkDocs and Material theme.

<!-- more -->

## What's New

We've built this website with several key features in mind:

### Beautiful Gradient Design

Our site features stunning gradient color themes that create a modern and engaging visual experience. The gradients flow throughout the entire site, from the header to individual components.

### Light and Dark Mode

Toggle between light and dark themes seamlessly. The site respects your system preferences and provides a comfortable viewing experience in any lighting condition.

### Full Responsiveness

Whether you're on a desktop, tablet, or mobile device, our website adapts perfectly to your screen size. All content is optimized for the best reading experience.

### Accessibility First

We've built this site with accessibility in mind:

- Proper heading hierarchy
- Sufficient color contrast
- Keyboard navigation support
- Screen reader friendly
- ARIA labels where needed
