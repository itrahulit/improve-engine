## Features

### Light and Dark Mode

Toggle between light and dark themes using the button in the header. The site automatically adapts to your system preferences.

Experience beautiful gradient color schemes throughout the site that create a modern and engaging visual experience.

### Hero Images

Each major page features an eye-catching hero section with gradient backgrounds and smooth animations.

This website is built using:

- **MkDocs** - A fast, simple static site generator
- **Material for MkDocs** - A beautiful and feature-rich theme
- **GitHub Pages** - Reliable and free hosting
- **Azure Static Web Apps** - Future deployment target
